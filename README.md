# React Chatbot 🤖

A simple chatbot built with React that can respond to predefined user messages.

## Live Demo

[View Website](https://yash-react-chatbot.vercel.app/)

## Features

- Chat interface with user and bot messages
- Custom chatbot responses
- LocalStorage support (messages remain after refresh)
- Clear Chat button
- Loading animation
- Responsive design for desktop and mobile
- Deployed online using Vercel

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite
- Vercel

## Installation

Clone the repository:

```bash
git clone https://github.com/yash-data-tools/Yash-react-chatbot.git
```

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```
